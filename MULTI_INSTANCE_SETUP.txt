💡 OPTIMIZATION FOR YOUR RTX 3090 (24GB)

Memory Usage Per Instance: ~2.5GB - 7.5GB (varies by model and batch size)

Recommended Configurations:

1. Conservative (Safer, guaranteed to work):
   NUM_INSTANCES=2 GPU_MEMORY_PER_INSTANCE=10000 ./run_multi_swarm.sh
   → 2 instances, ~10GB each, 4GB buffer

2. Balanced (Recommended):
   NUM_INSTANCES=3 GPU_MEMORY_PER_INSTANCE=7000 ./run_multi_swarm.sh
   → 3 instances, ~7GB each, ~3GB buffer

3. Aggressive (Maximum utilization):
   NUM_INSTANCES=3 GPU_MEMORY_PER_INSTANCE=6000 ./run_multi_swarm.sh
   → 3 instances, ~6GB each, requires careful monitoring
   → Use smaller models or float16 precision

Tips:
  - Start with 2 instances, monitor GPU with nvidia-smi
  - Add 3rd instance if memory allows
  - Use different seeds per instance for diversity
  - Monitor with: watch -n 1 nvidia-smi

================================================================================
🔧 TROUBLESHOOTING
================================================================================

Problem: Out of GPU memory
Solution: 
  ./control_instance.sh stopall
  NUM_INSTANCES=2 ./run_multi_swarm.sh

Problem: Instance won't start
Solution:
  ./control_instance.sh logs 1
  (Check logs for specific error)

Problem: Port already in use
Solution:
  lsof -i :3000
  kill -9 $(lsof -t -i:3000)

Problem: All instances keep restarting
Solution:
  AUTO_RESTART=no ./run_multi_swarm.sh
  (Then debug the failing instance)

Problem: Can't find Python
Solution:
  # Activate your Python environment first
  source ~/.pyenv/versions/3.11.9/bin/activate
  # Or use conda, venv, etc.
