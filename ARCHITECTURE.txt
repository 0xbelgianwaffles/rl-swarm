    │
    └──> Display Dashboard ──> Terminal output

CONTROL FLOW
================================================================================

control_instance.sh start N
    │
    ├──> Check if already running
    ├──> Create wrapper script
    ├──> Set environment variables
    ├──> Launch in background
    └──> Verify started

control_instance.sh stop N
    │
    ├──> Find PID
    ├──> Send SIGTERM (graceful)
    ├──> Wait up to 15 seconds
    ├──> Send SIGKILL if needed
    └──> Verify stopped

control_instance.sh restart N
    │
    ├──> stop N
    ├──> Wait 2 seconds
    └──> start N

COMMUNICATION ARCHITECTURE
================================================================================

┌─────────────────────────────────────────────────────────────────────┐
│                         Swarm Network                               │
│                    (P2P via Hivemind DHT)                           │
└─────────────────────────────────────────────────────────────────────┘
         ↑                    ↑                    ↑
         │                    │                    │
    ┌────────┐           ┌────────┐           ┌────────┐
    │Instance│           │Instance│           │Instance│
    │   1    │◄─────────►│   2    │◄─────────►│   3    │
    └────────┘           └────────┘           └────────┘
         │                    │                    │
         │                    │                    │
         └────────────────────┴────────────────────┘
                              │
                              ↓
                    ┌──────────────────┐
                    │  Shared GPU      │
                    │  (CUDA context)  │
                    └──────────────────┘

Each instance:
  • Has unique peer identity (swarm_N.pem)
  • Connects to same swarm network
  • Shares training updates via DHT
  • Uses separate GPU memory allocation

RESOURCE ALLOCATION
================================================================================

GPU Memory (24GB RTX 3090):
┌────────────────────────────────────────────────────────────────┐
│ Instance 1 │ Instance 2 │ Instance 3 │ System │ Buffer │       │
│   ~7GB     │   ~7GB     │   ~7GB     │  ~2GB  │  ~1GB  │       │
└────────────────────────────────────────────────────────────────┘
 0GB         7GB          14GB         21GB     23GB     24GB

CPU: Shared (all instances use same CPU cores)
Disk: Separate per instance (user/instance_N/)
Network: Shared (bandwidth shared across instances)
Ports: Unique per instance (3000, 3001, 3002)

SECURITY & ISOLATION
================================================================================

Instance Isolation:
  ✓ Separate process spaces
  ✓ Separate file directories
  ✓ Separate identity keys
  ✓ Separate network ports
  ✓ Separate log files
  ✓ Separate configs

Shared Resources:
  • GPU (via CUDA)
  • CPU & RAM
  • Network bandwidth
  • Disk I/O

Security:
  • Each instance has unique peer ID
  • No inter-process communication except via swarm network
  • File permissions respect user/group
  • No privilege escalation required

================================================================================
SCALING CONSIDERATIONS
================================================================================

Can you run more than 3 instances?
  
  Yes, if:
    ✓ Using smaller models (<1B parameters)
    ✓ Reducing batch sizes
    ✓ Using float16 or int8 precision
    ✓ Enabling CPU offloading
    ✓ Have sufficient GPU memory

  Monitor carefully:
    • watch -n 1 nvidia-smi
    • Look for OOM errors in logs
    • Reduce if utilization > 95%

  Maximum realistic: 4-5 instances on 24GB GPU with small models

================================================================================
PERFORMANCE EXPECTATIONS
================================================================================

Single Instance:
  • GPU Utilization: 30-50%
  • Memory: 6-8GB
  • Training Speed: 100%

3 Instances (Multi-Instance):
  • GPU Utilization: 80-95%
  • Memory: 20-22GB
  • Training Speed: 280-300% (2.8-3x throughput)
  • Overhead: ~10-15% per instance due to context switching

Bottlenecks:
  • GPU memory (primary limit)
  • CUDA context switching (minor overhead)
  • Disk I/O (if logging heavily)
  • Network (if bandwidth limited)
